# NER
Name Entity recognition training. Using open data. Learning project

## Environment setup
Set up environment using conda or uv or pip.
### Conda
```bash
conda create -f environment_cpu.yml # use for cpu
conda create -f environment_gpu.yml #use for gpu
```

### uv
```bash
uv init
uv sync
```


### pip
```bash
pip install -r requirements.txt
```
